# Formats for cargo xtask format-diff, one per line.
#
# A line that is exactly "#" or starts with "# " is a comment, empty lines
# are skipped. Lines are taken as they are, spaces included. A line that
# starts with a backslash is the format after that backslash, so "\# x"
# is the format "# x" and a lone "\" is the empty format.
#
# The servers are set up by setup_commands in xtask/src/format_diff/mod.rs:
# sessions alpha (windows 0 editor with three panes, 3 logs, 5 "café ☕"),
# beta, gamma (grouped with alpha) and δelta, user options @plain, @num,
# @neg, @float, @path, @dir, @utf8, @empty, @dotdot, @fmt, @punct, @hashbrace,
# @long, @spaces, @shell, @colour, @true, @false, @zero, @wopt, @popt,
# @sopt, environment FOO, EMPTYENV, SESSVAR, REMOVED (removed) and the
# buffers buf0 and buf1. The target is alpha:0.1.
